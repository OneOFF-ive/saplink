# 技能生成

把用户希望重复执行的工作整理成一份技能。先确定适用场景、所需输入、关键判断和期望输出。只有缺失的信息会实质影响结果时，才追问一个具体问题。修订时保留用户仍需要的流程和资料。

根目录必须有 UTF-8 的 `SKILL.md`，用 YAML frontmatter 写简短的英文小写连字符名称和易于识别使用场景的描述。正文只保留能帮助助手做决定的步骤、检查条件和输出要求。较长的规则、模板或示例放入子目录，在正文用真实相对路径引用。子目录名称按用途选择。

用 `draft_skill_package` 提交完整文件集。每个文件给出 `path` 和 `text`，最多八个文本文件。检查入口文件、相对链接和用户授权范围。技能内容可以指引工作，但不授予 SAP 写入、外部调用或脚本执行权限。
