# SapLink v1.0.9 — 安全依赖修复与测试结果判定优化

## 更新内容

- **依赖安全修复**：更新 body-parser、fast-uri 及相关 qs 依赖，修复已知的压缩请求处理和 URI 解析问题。
- **ABAP Unit 结果更准确**：修正空或空白执行时间被当作零耗时的问题，避免将未确认执行的测试误判为通过；有效的零耗时仍正常识别。
- **回归覆盖完善**：补充异常压缩请求与测试执行时间解析的回归用例，更新安全说明。

## 下载与升级

- Intel / AMD 64 位 Windows：`SapLink-1.0.9-win-x64-setup.exe`。
- Windows ARM64：`SapLink-1.0.9-win-arm64-setup.exe`。
- Skill：`SapLink-1.0.9-skill.zip`。
- 安装包和 Skill ZIP 均提供 `.sha256` 校验文件。
- 手动升级前，请通过托盘菜单退出应用并停止后台服务，再运行安装包。升级保留已有配置。
