# SAP 助手与运行时

SAP 助手在「工作空间」中提供 DeepSeek 对话，复用 SapLink 管理宿主和 SAP CLI。本文适用于包含该功能的安装版和源码开发预览。

## 启动方式

- **正式安装版**。从 SapLink 快捷方式或 `saplink ui` 打开管理页面。
- **源码开发预览**。双击 `scripts/start-agent-dev.cmd`，或运行 `npm run dev -- ui`。预览使用独立的配置、日志、端口和凭据。需要自定义目录时使用 `SAPLINK_DEV_CONFIG_DIR`，目录须与正式配置分开。两种环境的默认值见[本地数据说明](local-data.md#正式安装版与源码开发预览)。

在预览中看到连接缺少 SAP 密码时，请在该环境的「连接配置」中编辑连接，重新输入密码并测试。未显式配置 RFC 环境时，预览可以校验并复用安装版的 Java/JCo 和匹配的桥接类。可用 `SAPLINK_DEV_INSTALL_ROOT` 指定供预览检查的安装目录。

## 在页面中使用

1. 页面默认打开「工作空间」，右侧是「SAP 助手」。在「模型设置」保存 DeepSeek API Key，在对话输入框底栏选择模型。已保存的密钥显示掩码提示，留空保存会保留原值。
   表数据访问权限在每个 SAP 连接的编辑窗口中设置。未设置过该权限的旧连接默认开启，新建连接默认关闭；代码和表结构分析不需要开启它。
2. 系统列表优先恢复上次选择，没有有效记录时默认选中第一个连接；有连接时不提供空选项。没有连接时显示“暂无 SAP 系统”，通过旁边的管理图标添加。
3. 输入具体问题或对象入口，按回车或点击输入框底部右侧的发送图标；Shift+回车换行。默认允许将分析所需代码和元数据发送至已配置模型。
   可点击输入框下方的加号添加文件，或粘贴文件。支持任意后缀的 UTF-8 文本、PNG/JPEG/GIF/WebP 图片、带文字层的 PDF，以及 DOCX/XLSX/PPTX，每次最多 10 个，单张图片不超过 32 MiB，其他文件单个不超过 10 MiB，合计不超过 64 MiB。普通文本粘贴仍直接输入文字；部分应用或浏览器复制文件时不提供文件内容，此时请使用添加文件图标。PDF 和 Office 文件在本地提取文字，提取结果保存到会话附件。扫描 PDF 可先上传页面截图，旧版 DOC/XLS/PPT 可先另存为新版格式。图片保存在会话附件，识别时发送给 DeepSeek Flash，再由当前模型分析。切换会话或系统会清除未发送的文件。长文件先提供预览，助手可按需分页回读完整内容。删除会话时附件一并删除。
   输入框底部显示当前模型和推理等级。点击模型切换 DeepSeek 模型，点击推理等级或上下文档位可打开同一个菜单。高档使用 DeepSeek 的最高推理强度，任务可以持续思考和调用工具，SapLink 无固定轮次上限。上下文可选择 128K、512K 或 1M，默认 512K。展开会话详细信息可查看工作上下文估算、最近请求的实际输入量和已报告的累计用量。
   加号菜单还可搜索和引用已启用的技能或 MCP 服务。引用与附件一起显示在发送前的输入区，发送后跟随该条消息。引用提高扩展在本轮的优先级，仍沿用原有权限。

   可以直接在对话中设置或修改长期偏好。跨系统生效的说法和示例见[长期记忆](#长期记忆)。

   粘贴公开网址并请助手总结，即可直接读取网页标题和正文。网页读取不执行脚本，不使用浏览器的登录状态，重定向会重新核对目标。若系统 DNS 只返回代理使用的虚拟地址，会通过 Cloudflare 的公开 DNS 再查询该域名。搜索复用 DeepSeek API Key，只提交公开关键词，并由 DeepSeek 单独计费。读取或搜索成功时，回答会附来源链接。

   保存草稿会打开进度窗口，修改计划会逐项展示基线校验和保存结果。若保存失败，可点击「重新生成草稿」，让助手读取本次保存回执并根据原需求生成待审核的草稿。部分保存时，已成功的修改保留，结果不明确的项目先核实。

   在对话中要求生成 Word、Markdown 或文本文件，文件会出现在对话底部。也可以要求助手编写 Node.js 或 Windows PowerShell 脚本。点开脚本卡片核对代码，点击「运行脚本」后才会执行。脚本以当前系统用户权限运行，初始工作目录为临时目录。脚本运行结果可在卡片中查看，也可以继续在对话中请助手解读。写入 `output/` 且申报的输出文件可直接下载。
   通过左侧系统选择器切换连接或进入连接管理；未配置密钥时点击模型打开模型设置。模型与推理设置保留密钥，不改变连接权限；正在执行任务时不能修改。推理模式可能增加耗时与费用；模型思考内容会保存在本机任务历史中以支持工具调用，不显示在对话中，应与源码等任务资料同等保护。
   连接配置只保留“允许写入”开关。开启后，输入框下方显示“受控写入 / 完全写入”选项，默认受控；偏好按系统保存，会话保存自身模式。运行期间不能切换。模式只影响本客户端，CLI/MCP 可独立写入，第三方客户端自行管理安全与审批。CLI/MCP 不提供审批工具或公开审批编号参数。
   受控模式的源码修改、程序计划和单步操作统一进入草稿窗口。核对系统、对象、完整参数及源码后，只有“保存”“作废”“继续修改”三个操作。保存按钮本身就是一次确认；后台仍保留绑定目标、内容和请求的持久授权记录，不再要求用户记录审核、单独审批及再次执行。
   对源码修改，保存会重新核对 SAP 基线，并只保存非活动源码。即使模型旧计划含激活或 ATC，也不会随保存执行。成功后单独询问是否激活；ATC 是默认不勾选的选项，使用 SAP 实际返回的默认变式。激活前检查语法并再次核对已保存版本，源码变化或检查失败则停止。ATC 提交不等于检查完成或通过。单独请求的创建对象、激活、ATC、Unit 等操作则在审核完整参数后执行对应操作，不会额外触发源码激活。
   作废只放弃未提交修改，不回滚 SAP 已保存内容；执行中及结果未知的记录不能作为未执行草稿丢弃。失败后的“继续修改”直接启动助手，沿用原需求、原草稿和最新源码，不要求用户重新描述目标；仅在确有合并冲突或意图缺失时询问具体问题。普通未提交草稿的继续修改保留输入框已有文字，原草稿引用在后台绑定，用户可补充后发送。两种路径都仅生成新草稿，即使会话原先选择完全写入也不自动提交修复内容。
   保存失败后自动只读核对活动/非活动源码和连接、传输信息，将持久诊断交给助手解释原因并按需生成修复草稿。修复草稿仍须重新审核保存。明确未发出的临时连接故障最多自动重试一次，重试前再次验证相同源码基线；权限、锁、传输及基线冲突不盲目重试。超时或连接重置的未知请求也不重跑；读回与草稿相同只证明当前源码符合目标，不证明原请求、锁、激活或检查的完整结果。无法核实时保留阻断与记录。
   保存和激活结果持久绑定会话、连接和草稿，重复点击、刷新页面和重启不会重新提交。重新打开中断草稿会检查执行日志并只读核实；仍在运行的宿主不会被当成已停止。保存成功、未知及已作废草稿都不能借旧执行接口再次写入。完全写入模式原有直接执行行为保留，后台仍检查 SAP 权限、锁、版本及传输要求；内部授权来源以 client_full 区分。
   回答完成后可在详情中确认“压缩对话”，调用模型整理工作上下文，可能产生 Token 消耗；原始对话保留，摘要可能遗漏细节。整理期间不能提交其他任务。
4. 问题和回答之间显示紧凑的执行活动流：当前动作、耗时及可折叠的实际操作。连续重复读取合并显示，展开可看成功/失败、耗时及操作编号；停止和缺失记录不会标为成功，不显示模型内部思考或推算完成百分比。
5. 可停止或继续停止、中断的任务。页面刷新后可从历史任务重新查看，无需重复确认数据发送。输入框中的上下文设置可调整自动整理阈值，普通用户可保持默认。

“新对话”创建独立任务；在已有对话中直接发送问题会沿用同一任务、系统和访问范围，复用已读资料及前面的问答。每轮回复保留在同一对话中，刷新后恢复本标签页选中的对话。用户切换系统时显示该系统历史并恢复该系统选中的会话；没有历史时显示新对话，不把原上下文发送到另一连接。

切换历史会话时立即更新选中状态并显示加载提示，随后加载对话和报告；加载失败可重新连接，快速切换不会显示其他会话的迟到结果。

历史问答按需分页加载，只返回用户问题与最终回答，不返回内部工具消息、系统指令或工作摘要。完整问答与模型工作上下文分开管理，整理上下文不会删除公开问答。旧任务可直接查看，追问前会将旧检查点完整回合归档。

回答生成时实时显示，页面标注未完成；流式连接断开不停止后台任务，重连可恢复当前进程内的草稿。停止、失败或宿主重启不会把草稿保存成正式回答，任务历史和导出只包含已完成回复。模型工具回合仍完整校验后才执行，流式预览不能提前触发工具。按原要求，分析准确性与精确源码证据后续优化。

会话列表采用单行短标题，不显示日期或菜单。自动标题优先概括 SAP 对象和分析目的，最多18个字符；旧会话没有手动标题时使用同一规则显示，不改写原问题或手动命名。鼠标悬停或键盘聚焦时显示置顶和删除，触屏常显；操作对应当前行且不切换正在查看的报告。双击标题或按 F2 原位编辑，回车/失焦保存、Esc 取消，轮询不会打断编辑。置顶会话排在前面，并跳过批量清理；用户仍可明确确认单独删除置顶会话。界面不再提供导出对话，仅保留分析报告导出。

工作台省略重复标题、目标和常驻说明。连接管理、模型设置、报告导出/更新及历史清理使用带名称和悬停提示的图标按钮；表数据访问权限在连接配置中管理。缺少配置、执行失败、权限撤销和任务中断仍显示相应提示。

顶部入口为 SAP 助手、连接配置、MCP 服务和系统设置。访问令牌整合在 MCP 服务页；系统设置包含软件更新、RFC 运行环境、MCP 连接缓存和历史日志清理。报告区保留固定底栏显示字符数，正文独立滚动。

报告由四类对象统计、关键对象表、工具调用记录及详细分析组成。新报告要求模型用“对象 / 类型 / 用途 / 关联”表格列出实际定位对象，界面按对象名称去重统计；统计仅覆盖清单中的对象，不表示 SAP 全库或完整依赖数量，也不等于语义已验证。缺少清单时显示未知数量并保留原分析。工具标签取自执行器的成功/失败事件，随报告保存，普通追问不改变该快照；较早事件已归档时标注为近期记录。旧报告未保存的对象清单或工具记录不自动补造，可通过更新报告重新整理。

报告按固定顺序组织为对象、调用链、业务解读、影响分析、改造建议、完整结论六类页签，仅显示实际有内容的类别，不使用“能力总览”。模型以对应的 Markdown 二级标题分类，三级标题组织对象清单、核心调用链与依赖、业务流程/解释/风险、影响摘要/范围/回归，以及建议改造和最终结论。流程列表显示为步骤卡片，diff 区分增删行。影响摘要只展示有依据的已提供指标，不自动推算风险或依赖数量。建议区标明未执行写入，当前 Agent 仍为只读。切换页签回到内容顶部，定时刷新保留选中页签；旧版报告将对象清单单独呈现，其余原文保留在完整结论。

报告与对话使用本机提供的 Marked 和 DOMPurify 渲染 GitHub 风格 Markdown，支持标题、加粗、斜体、删除线、行内/块代码、嵌套列表、引用、表格及任务列表。原始 HTML 仍按文字显示，远程图片不加载；只允许手动打开 HTTP/HTTPS 链接，禁用脚本和交互表单。旧报告仅改变呈现，不改写保存的原文，也无需再次调用模型。手机端依次显示聊天历史、分析报告与对话，执行轨迹折叠在对话中。

## 长期记忆

在工作空间的「SAP 助手」对话中，用平时说话的方式描述偏好即可。

| 你的意图 | 可以这样说 |
| --- | --- |
| 设置全局偏好 | “以后不管用哪个 SAP 系统，报告都先给结论，再列证据。” |
| 修改已有全局偏好 | “把之前的全局报告偏好改成先列证据，再给结论。” |
| 只在当前连接长期使用 | “以后分析这个系统的 ABAP 程序时，先列出主程序和直接 INCLUDE。” |
| 只用于本次任务 | “这次报告先给结论。” |

模型识别偏好的主题和范围，修改时沿用已有主题。全局保存需要当前用户的原话明确表达跨系统或全局范围。如果范围有歧义，可以把适用范围和偏好一起说清楚，比如“以后所有 SAP 系统的报告都先列证据”。需要指定精确主题时，也可使用 `记住全局偏好：报告格式 = 先给结论再列证据`。

当前连接的同主题偏好优先于全局偏好。带有 SAP 工具来源的排查经验按连接隔离。通过校验的记忆会在本轮回答完成时保存。记忆提供历史线索，SAP 当前状态仍需现场核实，写入权限由本轮设置和 SAP 权限决定。

记忆保存在本机配置目录的 `agent/memory/library.sqlite`。SQLite FTS5 根据中文词片段和 SAP 对象标识对相关记录排序，再按约 1,800 token 的上下文预算选取。检索在本机完成，选中的主题和内容会随对话发送给已配置的模型。旧 JSON 记忆文件保留在原处，新库从空库开始。

## 自定义扩展

在 SAP 助手对话栏打开「模型设置」，切换到「技能」或「MCP」。

安装包自带「技能生成」和「SapLink」，两项内置技能始终启用，内容随应用版本更新。技能生成可在普通对话中生成可下载的技能 ZIP，也为「对话创建技能」提供编写规则。SapLink 指导助手用客户端的内置 SAP 工具验证连接、读取对象并处理修改草稿。

在 SAP 助手对话中，可列出或测试已配置的自定义 MCP，查看对外 SapLink MCP 的运行状态。添加、编辑、启用、停用、移除自定义服务，以及启停对外 MCP，均由助手生成确认卡，用户确认后执行。新添加的自定义服务默认停用，访问令牌在设置中填写。

- **技能** 列表显示已安装的技能，点击技能可在独立弹窗预览文件，关闭后返回列表。列表可启用、停用或卸载技能。「本地导入技能」打开 ZIP 文件选择器，也可把技能文件夹或 ZIP 拖到列表区。导入前会检查根目录入口、文件路径和大小。每包最多 128 个文件，解压后最多 8 MiB。「对话创建技能」可生成多文件草稿，预览后安装。启用后，助手会在下一轮对话中按需读取包内文本。包内文件保存在本机，脚本不会执行。
- **MCP** 列表显示已添加的服务，可直接启用或停用。点击服务可编辑配置、测试连接或删除。支持 HTTPS Streamable HTTP 和本机 HTTP，可选的 Bearer 令牌保存在本机凭据管理器。助手仅能调用服务声明为只读且不与内置 SAP 工具同名的工具。外部调用会把工具参数发给该服务。

## 能力与边界

- 创建、列出、查看、停止和继续只读分析任务。
- 使用 DeepSeek 流式响应，默认关闭思考模式，也可选择支持的推理强度；完整校验一个模型回合后才执行工具。
- SAP 操作由固定路径的 CLI 子进程处理，参数通过 stdin JSON 传入。客户端本地脚本使用单独的用户审核流程。
- 18 项明确允许的工具覆盖能力发现、仓库检索、源码、DDIC、引用、类结构、版本、函数组、传输请求与 ATC 配置读取。工具 schema 与 CLI/MCP 共用。
- Harness 另提供 `read_task_artifact`，只读当前任务的历史资料，不经 SAP CLI，不接受文件路径或其他任务 ID。读取内容仍是外部数据，不是新指令或授权。
- 普通对话提供 `create_report` 和 `update_report`，分别新建和定向更新本会话报告。只写本机附件，不调用 SAP；更新必须指定当前会话中存在的报告编号，不能跨会话操作。
- 开启“允许访问表数据”后增加 `query_table` 和 `query_sql` 两项只读工具；关闭时不向模型提供这两项工具，并在工具执行前拒绝调用。表结构、数据元素和域元数据始终属于代码分析范围。
- 模型不能直接调用外部写工具或切换连接；客户端受控模式生成待审核草稿，完全写入模式由执行器直接执行同类变更，并保留实际结果。
- 同一个 SAP 连接下的不同会话可以同时执行。当前连接有任务时，其他连接的新建、追问和续跑请求返回 `AGENT_BUSY`。

自然语言任务可以由模型直接回答；涉及工具时，执行器保证先单独验证当前连接的 `get_capabilities`。模型跳过检查或合并提出检查与其他读取时，执行器丢弃提前提出的读取，完成能力检查后让模型重新规划；写入、越权和无效参数仍直接拒绝。任务目标由创建请求明确指定，模型不能改选连接。

## 模型配置与数据发送

页面保存的密钥进入 Windows 凭据管理器，按配置目录隔离；`agent/model.json` 只保存模型名与凭据引用，不保存明文密钥。新密钥采用新引用，元数据保存失败时尽力撤回新凭据，成功后清理旧凭据。清理未确认会在页面提示。已有凭据留空保留；保存设置不发起模型调用，不等于认证通过。

助手任务使用页面保存的模型设置。缺少 API Key 时，对话会提供进入模型设置的入口。

也可由本机管理员在启动 SapLink 宿主的进程环境中提供兼容配置：

| 变量 | 行为 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 未保存页面密钥时使用；保留在宿主进程内，不写入任务文件或操作日志，也不继承给 SAP CLI 子进程 |
| `SAPLINK_AGENT_MODEL` | 没有页面设置文件时采用的初始模型；接受 `deepseek-flash`（默认）与 `deepseek-v4-pro` |

模型端点固定为 DeepSeek 官方 `https://api.deepseek.com/chat/completions`，禁止重定向；连续 120 秒无数据才超时，单次请求最多 393216 输出 tokens，SSE 流最多 256 MiB。启用思考模式时将推理内容用于后续工具调用，切回关闭时不再发送；外部工具扩展尚未开放。

按产品默认设置，创建与继续任务允许将任务提示词、所选连接 ID/Client、选入上下文的源码和元数据发送到已配置的模型服务，页面保留说明，不要求逐任务勾选。接口为兼容旧客户端保留 `allow_model_data`，省略时默认为 true；显式传 false 会拒绝启动，不会默默忽略。

表数据访问由各连接的 `allow_table_data` 控制，保存在本机连接配置中，并在共享工具执行层限制 `query_table` 和 `query_sql`，适用于 SAP 助手、CLI 和 MCP。新建连接默认关闭，未设置过权限的旧连接默认开启；旧版 `agent_allow_table_data` 的显式值会迁移，已明确关闭的连接保持关闭。开启后，助手可以读取实际表行并将结果发送至模型；该开关不绕过 SAP 用户权限、只读 SELECT 验证、Client 限制、行数和结果大小上限，也不限制表结构等元数据读取。已有连接目标不可修改；更改 Client 或用户名时保留该连接的权限，除非手动修改。连接配置编辑沿用现有限制：MCP 服务运行时须先停止服务。

每个任务记录创建时的表数据权限。开启设置不会扩大旧代码任务的范围；关闭对应连接的权限后，原先允许表数据的任务不能继续发送历史上下文。运行时在模型调用及工具读取前后检查，关闭后不把新读取结果交给模型。旧版模型级 `allow_table_data` 不再参与权限判断；旧连接的默认值在下次保存配置时写入。该开关不删除之前保存在本机任务历史中的数据。

管理 API 的状态只报告是否存在模型配置，不把密钥存在当作认证成功。

## 本地接口

所有接口位于现有本机管理端口，共用 `X-Admin-Token` 认证、Host 和 Origin 校验。变更接口必须来自当前管理页面同源。没有新增公开监听器或 MCP Agent 工具。

| 方法与路径 | 用途 |
| --- | --- |
| `PATCH /api/agent/tasks/:id/write-mode` | 更新当前会话的客户端写入模式，拒绝运行中或未开启写入的连接 |
| `GET /api/agent/status` | 配置状态、模型、运行中的任务列表与锁定的 SAP 连接 |
| `GET /api/agent/model` | 模型与配置状态；不返回密钥或凭据引用 |
| `PUT /api/agent/model` | 保存模型与可选新密钥；有任务执行时拒绝变更 |
| `GET /api/agent/tasks` | 最多 100 项任务摘要，按创建时间倒序；可用 connection_id 筛选系统 |
| `POST /api/agent/tasks` | 创建任务，返回 202 和任务 ID；可传 `allow_table_data: false` 缩小本任务权限，不能传 true 扩权 |

| `GET /api/agent/tasks/:id/changes/:changeId` | 查看当前会话中已保存的源码变更草稿及完整差异；不写入 SAP |

| `DELETE /api/agent/tasks/:id/changes/:changeId/review` | 明确确认后撤销当前审核记录；不改变 SAP |
| `GET /api/agent/tasks/:id/operations/:operationId` | 返回本会话操作草稿、完整参数和审批状态 |
| `GET /api/agent/tasks/:id/workflows/:workflowId` | 返回任务计划、按步骤投影的执行进度和关联审批；执行期间可查询 |

| `POST /api/agent/tasks/:id/operations/:operationId/execute` | 确认后消费审批并执行一次 |
| `POST /api/agent/tasks/:id/operations/:operationId/resolve` | 记录用户已人工核实不确定结果；不自动验证 SAP |
| `PATCH /api/agent/tasks/:id` | 修改 title 或 pinned；运行中的当前会话不可修改 |
| `GET /api/agent/tasks/:id/export` | 下载公开问答的 Markdown 文件 |

| `GET /api/agent/tasks/:id` | 查看状态、最近事件、累计事件数、整理次数、上下文阈值、结果与安全错误 |
| `POST /api/agent/tasks/:id/stop` | 停止当前任务并等待当前本地执行收敛 |

创建请求示例，`connection_id` 必须来自本机实际连接配置：

```json
{
  "prompt": "解释指定程序的主要逻辑，并列出尚未核实的依赖。",
  "connection_id": "实际连接UUID",
  "allow_model_data": true
}
```

继续请求正文可以为空对象 `{}`，也兼容 `{"allow_model_data":true}`。任务列表不返回答案和事件，任务详情不返回内部模型历史与目标指纹。任务不存在、参数无效、未配置模型或执行冲突沿用管理 API 的结构化错误响应；异步执行失败保存在任务的 `error` 中。

状态与执行轨迹通过 HTTP 轮询刷新，正文优先通过 SSE 快照实时传递。实时连接中断后最多重连五次，对话区显示当前次数。全部失败时，本轮正文改由 HTTP 详情轮询的草稿快照继续显示。切换对话或隐藏页面会断开对应实时连接，后台任务继续执行。接口通过请求头传递认证，实时连接数量有上限。

当前轮次的进度摘要和工具步骤按发生顺序显示在问题与最终回复之间。运行时自动展开，结束后收起为「用时」一行，点击可重新展开。轮询保留用户当前的展开选择。展开有回执的工具步骤时，结果直接显示在该步骤下方。长结果滚动到底部时自动加载后续内容。正文开始输出时才显示回复区。较早事件已归档时标注近期记录，没有开始事件时不计算单项耗时。

工作台使用顶部菜单，桌面下方分为左侧系统与聊天历史、中间分析报告、右侧连续对话三个独立滚动区域。窄屏按可用宽度排列，手机依次显示历史、报告和对话。系统选择保存在本机，每个系统分别记住当前浏览器标签选中的会话。切换会话同步加载其报告与问答，后台任务继续执行。当前连接的所有任务结束后，系统选择恢复可用。

会话可以保存多份独立报告。页面的普通发送采用 output_mode=chat，由模型决定是否调用本地 create_report 工具新建独立成果；普通解释和闲聊直接回答。页面不再提供新建/更新报告按钮，用户通过自然语言提出要求。create_report 新建，update_report 按真实编号更新完整内容；发送消息时带上当前所选报告编号及历史资料，方便解析“这份报告”，但选中本身不是更新授权。目标不明确时要求模型先澄清。原 report 模式及 report_id 接口保留用于兼容旧客户端。报告选择在本标签页记忆，切换系统或会话时加载相应列表；新增报告完成后展示新报告，普通追问不改变已有报告。接口的创建默认仍为 report 以兼容旧客户端，messages 默认 chat。每份报告有稳定编号与独立标题，更新生成新附件并只移动对应报告的指针，其他报告不变。重复的同轮模型发布按内容和标题去重，避免停止恢复时产生重复副本；已完整保存的报告不因后续回复失败而删除。旧单报告及无报告索引的会话按需迁移，原报告原文保留。列表、切换和导出不访问模型或 SAP。

报告列表鼠标悬停或使用键盘聚焦时显示重命名和删除按钮，触屏常显；仅选中报告不会显示按钮。操作其他报告不会切换当前报告。删除需确认，删除当前报告后自动选择剩余报告，最后一份移除后显示空状态。操作校验报告版本，运行中的会话不可管理报告。移除仅删除报告索引，不删除会话、对话历史或已导出文件；本机附件保留，直到整个会话被删除。

实时文本按模型回合重置，摘要整理过程不输出给页面。密钥脱敏跨文本分段处理，避免密钥被拆成多个片段时逐段暴露；未经完整响应验证的文本不进入任务问答历史。

## 执行与恢复

任务创建时记录实际登录目标的指纹，覆盖连接 ID、地址、RFC 信息、Client、用户名与语言。每轮和每次工具调用前重新检查；CLI 取得 `config.lock` 后再次核对指纹，随后才建立 SAP 操作对象，避免目标检查与执行之间的配置变更。

单项工具失败会记录在执行轨迹中，并以结构化错误返回给模型。助手可以修正参数、改用其他已授权的方法，或根据已核实的结果继续回答。参数校验失败的批次整体不执行。连续三轮工具调用全部失败时，助手停止调用工具并整理回复。SAP 能力验证失败后仍可对话，SAP 操作需等待验证成功。连接身份变化、会话级权限撤销或写入结果不确定时，由本机在当前对话回复原因，暂停对应操作，保留历史和写入回执。模型请求失败或用户主动停止时，分别标记为失败或已停止。

模型拒绝输入长度时，助手会在保留原始历史的前提下尝试更紧凑地压缩历史，然后重试一次。模型返回长度截断时，正文最多自动续写两次，续写不提供工具，成功后合并成一条回答。工具参数截断时重新生成完整工具回合，截断的参数不会执行。恢复仍未完成时，保留会话和已保存的报告，并在对话中说明。

任务检查点保存在配置目录下 `agent/tasks/<UUID>.json`，包含提示词、当前工作上下文、工作摘要、答案及最近执行事件，可能含客户源码。完整工具结果、完整回合、整理前的上下文和较早事件保存在 `agent/tasks/<UUID>/artifacts/`，以 SHA-256 标识并在回读时验证完整性。回合归档通过 previous 指针保留历史；旧任务仍可读取。

目录及文件使用当前用户的私有权限请求；Windows 实际隔离仍取决于目录 ACL，不能防止同一操作系统用户读取数据。资料归档先于检查点提交，中途停止可能留下未被检查点引用的附件，不会把未完成的工具批次发送给模型。

快照通过临时文件、同步和替换保存；宿主内读写串行化，Windows 文件占用导致的替换错误有有限重试。损坏历史文件不自动执行或删除，也不阻止管理界面启动；直接访问该任务返回无法读取的错误。

- 启动时将原 running/queued 状态转为 interrupted，不自动访问模型或 SAP。
- 继续任务前再次核对连接身份；身份改变后需要重新选定目标创建任务。
- 只保存完整的 assistant/tool 回合。中断时已发出的只读请求可能已完成，但尚未完成的回合不会作为上下文提交；继续时可重新读取。
- 停止与任务超时停止后续模型和工具调用；终止本地读取进程不保证 SAP 服务器已取消请求。现有锁诊断和恢复规则仍适用。
- 不自动重试模型请求或 SAP 工具调用。

单次 DeepSeek 请求的 `max_tokens` 使用官方最高值 393216（384 × 1024），两个支持的模型一致；按 1M 总窗口和当前输入估算，在剩余空间不足时下调本轮输出预算。估算不是精确分词，实际可生成长度仍由服务端输入与输出共享的模型上下文窗口约束。持续接收数据时不设置两分钟总超时；连接或流连续 120 秒无数据才超时，用户仍可随时停止。回答和报告最多 4 Mi 字符，工具参数最多 8 Mi 字符，SSE 流最多 256 MiB；这些是本机资源边界，不是 token 数。

任务不设模型请求总轮次、工具调用总次数或总运行时长上限，持续执行直到完成、用户停止或实际错误。调用次数仍累计记录，旧版因预算失败的任务可由用户继续。单次模型请求和 CLI 调用仍分别保留超时，避免单次请求永久挂起。

不再用历史累计 128 KiB 作为任务终止条件。工作上下文达到阈值时自动整理历史摘要，保留原始用户目标及可容纳的最近完整回合，完整历史先归档。保留回合的预算先扣除固定指令、工具定义和任务资料，并预留摘要空间；连接参数由任务注入，不在每个模型工具定义中重复提供，执行时仍校验完整参数及连接身份。工作摘要由同一个已配置模型生成，计入模型请求数；作为低信任的历史资料进入后续上下文，不提升为系统指令。重要证据应按附件回读核对，摘要不是事实验证。

摘要输入使用被移出工作窗口的完整回合，不再只截取每个源码页的前部，以免遗漏页面后半的控制流。执行器另持久记录源码附件已提供的字符区间，并在后续上下文中明确给出；仅在完整工具批次提交后更新，整理或重启不会把已提供范围清空。记录表示资料曾被提供，不表示模型已理解正确。工作窗口展示最近八个源码附件的进度，完整轨迹仍可沿归档回读。

上下文可选 128K、512K 或 1M，默认 512K，下次发送或继续任务时应用。选择 1M 时会为模型生成保留空间，接近窗口上限时提前整理。估算使用消息与工具 schema 的 JSON 字节数除以 3，再加消息开销。

摘要失败或被停止时保留原检查点，不安装无效摘要；支持继续中断或摘要故障任务。摘要前后、附件回读前后仍核对连接身份和表数据权限，不因压缩或回读扩大权限。关闭表数据权限后，原数据任务同样不能继续发送历史资料。

原始仓库结果超过 48 KiB 时，模型收到明确标注的不完整预览及附件标识，可按需分页回读；小结果也带原始附件引用。资料回读每次最多 16000 字符，注明偏移、是否还有后续及历史性质；源码视图保留精确源码文本和起始行。能力发现仍保留 64 KiB 边界，CLI 输出流最多 4 MiB，单个附件最多 32 MiB，单个工作检查点最多 64 MiB，本地任务最多 100 项。这些是单项资源保护，不是累计历史上限。

事件超过 512 条后归档较早部分，检查点保留最近 256 条，并继续使用全局递增序号。界面说明当前只展示较近记录；能力检查状态单独持久化，不依赖旧事件是否仍在窗口中。

任务记录模型返回的累计 `model_usage`，包含摘要请求和普通请求。`reported_requests` 表示提供用量的响应数；`usage_complete` 仅在所有已记录请求均有返回用量时为 true。取消/失败请求可能已产生消耗而未返回用量，因此这些统计不是精确账单，也不据此推算未知请求为零。

清理界面默认保留当前会话，按更新时间选择30天前、7天前或全部非固定历史，展示候选清单后再确认。执行时只处理清单中的记录；若会话已更新、被固定或已在运行则保留。单独删除同样绑定确认时的更新时间，避免删除随后新增的内容。删除仅限配置目录的对应UUID任务检查点与附件，不操作连接、密钥、SAP对象或用户已导出的文件。

删除先将检查点移动到本机删除标记目录，再清理附件。若部分附件暂时不能删除，会明确报告 cleanup_pending，下次启动继续清理；不把部分删除误报为全部物理清除。自动定时删除、无进展检测、无人值守任务恢复、业务澄清、证据卡片和通用工具失败恢复仍属于后续工作。没有以本次压力回归代替真实系统多小时验收。

连续对话、实时输出、会话管理及任务清理已接入开发版；下一步继续日常使用稳定性、安装版交付和兼容验证，模型内容准确性和证据引用另作后续优化。
